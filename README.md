# ☕ Pixels & Coffee

A creative personal portfolio website designed to showcase my journey, skills, projects, experience, certifications, and resume through an interactive and visually engaging web experience.

# ✨ About the Project

**Pixels & Coffee** is my personal portfolio website, created to present my professional profile in a creative and interactive way.
The website includes separate sections/pages for my introduction, skills, projects, experience, certifications, resume, and contact information. Visitors can navigate through these sections using interactive buttons and explore my profile easily.

# 🚀 Features

- ☕ Welcome page with a coffee-inspired theme
- ✨ Animated loading screen with steaming coffee
- 👩🏻‍💻 About Me section
- 🛠️ Skills section
- 💻 Projects showcase
- 💼 Experience section
- 📜 Certifications section
- 📄 Downloadable Resume
- 📩 Contact Information
- 🖼️ Interactive visuals and animations
- 🌐 Multi-page navigation
- 🎨 Creative and responsive portfolio design
- ❤️ Thank You page at the end of the experience

# 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
